# Website media slots

The landing page ships with optimized static screenshots, so it is complete without the
final recordings. Add these files later and `script.js` will select them automatically:

- `hero.gif` — full vertical workspace and native widgets.
- `embedding.gif` — select, embed, move, resize and overlap an external window.
- `productivity.gif` — smooth navigation between workspace pages.

Keep the names exact. WebP or MP4/WebM versions are preferable for performance once the
recordings are final, but the requested GIF paths work without changing the HTML.
