What it is

Your second monitor, as a focus workspace.

PomoDock is an open-source Windows app for a vertical second monitor. The main screen stays on the work. The other screen holds the Pomodoro timer, the list, the habits, the notes, and—if you want—a live window from another app.

No account. No PomoDock server. Data lives in SQLite under %LOCALAPPDATA%\PomoDock. You can import a Pomofocus CSV so years of sessions are not thrown away.

The method

What is the Pomodoro Technique?

The Pomodoro Technique is a time-management method by Francesco Cirillo. You break work into short, timed intervals—traditionally 25 minutes of focus—separated by a short break. Each interval is a pomodoro, named after the tomato-shaped kitchen timer Cirillo used as a student.

The point is not a prettier clock. It is to work in a closed block, stop when the alarm rings, and come back. PomoDock keeps that rhythm on the second screen so the timer does not fight the editor for space.

How to use the Pomodoro timer

  1. Move PomoDock to the secondary / vertical monitor.
  2. Add the timer. Optionally add tasks, habits, notes, or another app’s window.
  3. Start focus (Space, when no text field is focused). Work for one pomodoro.
  4. When the alarm rings, take the short break. After a few cycles, take a long break.
  5. Repeat until the task is done. History, streaks and reports stay on this PC.
  6. Optional: open the agent, set a DeepSeek key, and ask it to add a task or mark a habit.

Kit

What ships in 0.3.0

Pomodoro

Focus, short break, long break. Rhythms, sounds, skip, and a focus history you can export.

Pages

An infinite grid of canvases. Drag empty space or use the page dock. Rename a page; mark one as home.

Tasks & To Do

Estimates, priorities, dates. Sorted by recent use; switching missions asks whether to keep or save the timer.

Habits

Targets, streaks, XP, levels and a heat map. The board is a lens on a shared book.

Notes

Rich text, checklists, colour, searchable history. Closing a note does not delete it.

Calendar

Month, week, agenda. Repeating events and reminders that actually ring.

Finance

USD and MXN in the same book. Totals in the currency you pick. Rate, charts, periods.

Memento & startup

A life-weeks widget. Optional open-at-sign-in that restores window, page, task, and timer.

New in 0.2

A private agent on the same canvas.

Talk or type. The agent plans a change, you confirm, then it runs tools on this machine: todos, habits, notes, calendar, finance, widgets, pages, layouts, sounds, settings.

Reasoning can go through DeepSeek when you set an API key. The tools and the data stay local. Destructive steps ask first. Some things stay out of reach on purpose (the HWND picker, closing the app shell).

It is not a chatbot taped on the side. It is another widget that can operate the workspace you already see.

Why this, not a tab

Stop making the timer compete with the work.

A Pomodoro site in a browser tab

  • Lives on the main screen
  • Gets buried under the editor
  • Usually one function: the clock
  • History locked in that site’s account

PomoDock

  • Designed for the second monitor
  • Timer plus the rest of the kit
  • Real Windows windows as widgets
  • Local SQLite, MIT, optional agent

Quick answers

FAQ

Is this a Pomodoro timer?

Yes. Focus / short / long, with history. It is also the workspace around that timer: tasks, habits, notes, calendar, finance, and embedded apps.

Can I import Pomofocus history?

Yes. Export the report from Pomofocus, then import the CSV or TSV. Sessions map into native reports. Re-imports deduplicate; a safety copy is taken first.

Do I need an account?

No. Nothing is created on a PomoDock server. The workspace stays on your PC.

What does the agent need?

For chat, a DeepSeek API key in Settings. Voice dictation uses Whisper on-device. Tools never send your ledger or notes to “the cloud” as a product backend.

Will Windows block the installer?

The build is not code-signed. SmartScreen may warn; choose More info → Run anyway. Smart App Control can block unsigned local rebuilds.

Is it free?

MIT. The installer is free. DeepSeek, if you use the agent, is billed by them, not by PomoDock.
